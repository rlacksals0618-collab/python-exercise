### [c03.py](c03.py)

### [c09_starter.py](c09_starter.py)
점수(0~100)를 입력받아 학점을 판정합니다. 100점은 `Excellent!`, 범위를 벗어나면 `점수 범위 오류`를 출력합니다.

| 명령어 | 설명 | 예시 |
|---|---|---|
| `elif 조건:` | 앞 조건이 거짓일 때 다음 조건을 검사 | `elif score >= 90:` |
| `or` | 둘 중 하나라도 참이면 참 | `score < 0 or score > 100` |

조건은 위에서부터 차례로 검사하고, 처음 참이 된 블록 하나만 실행됩니다.

| 점수 | 출력 |
|---|---|
| 100 | Excellent! |
| 90~99 | A |
| 80~89 | B |
| 70~79 | C |
| 60~69 | D |
| 0~59 | F |

### [c09_work.py](c09_work.py)
근무 시간을 입력받아 급여를 계산합니다. 시급은 10,000원이고, 40시간을 넘는 시간은 1.5배로 계산합니다.

| 명령어 | 설명 | 예시 |
|---|---|---|
| `if` / `elif` / `else` | 음수 입력 오류, 초과 근무, 일반 근무를 구분 | `elif hour > 40:` |
| `int()` | 실수 결과를 정수로 변환 (소수점 버림) | `int(550000.0)` → `550000` |

```python
money = 1.5*pay*(hour-40) + pay*40   # 초과분 1.5배 + 기본 40시간
```

`50`을 입력하면 `550000 원`, `30`을 입력하면 `300000 원`이 출력됩니다.

### [c12.py](c12.py)
리스트 `[4, 5, 7]`의 합계를 누적하면서 출력하고, 5 이상인 수의 개수를 셉니다.

| 명령어 | 설명 | 예시 |

### [chwk.py](chwk.py)
**과제** - 높이를 입력받아 `*`로 크리스마스 트리 1개를 그리고, 아래에 줄기 `I`를 출력합니다.

| 명령어 | 설명 | 예시 |
|---|---|---|
| `문자열 * 숫자` | 문자열을 숫자만큼 반복 | `"*"*3` → `***` |
| `print(..., end="")` | 출력 후 줄을 바꾸지 않음 | 공백과 `*`을 한 줄에 이어서 출력 |
| `range(1, height+1)` | 1부터 height까지 반복 | 트리의 각 층 |

n번째 줄은 왼쪽 공백 `height-n`개 + 별 `2n-1`개로 구성됩니다. 높이 `3`을 입력한 결과:

```
  *
 ***
*****
  I
```

### [chwk(2).py](<chwk(2).py>)
**과제** - [chwk.py](chwk.py)를 확장해 높이와 나무 개수를 입력받아 트리를 가로로 여러 개 나란히 그립니다.

| 명령어 | 설명 | 예시 |
|---|---|---|
| 중첩 `for` | 바깥은 층(줄), 안쪽은 나무 개수만큼 같은 층을 반복 출력 | `for number2 in range(1,serial+1):` |
| 오른쪽 공백 | 나무 사이 간격을 맞추기 위해 별 뒤에도 공백 출력 | `print(" "*vacant, end="")` |
| `print("")` | 한 층을 다 그린 뒤 줄 바꿈 | |

높이 `3`, 개수 `2`를 입력한 결과:

```
  *    *
 ***  ***
**********
  I    I
```

맨 아래층은 양옆 공백이 0개라서 나무끼리 붙어서 출력됩니다.

# 바닷속 탈출

깊은 바닷속에서 눈을 뜬 주인공이 발판을 밟고 올라가 수면 위 출구로 탈출하는 플랫폼 게임입니다.

## 🎮 바로 플레이하기

**https://claude.ai/artifact/PLTQaUA6T2p1dpP4ZBr2FA**

Chrome이나 Edge로 위 주소를 열면 설치 없이 바로 플레이할 수 있습니다. 휴대폰으로 열면 화면 아래에 터치 버튼이 나옵니다.

링크가 열리지 않으면 아래 [파이썬으로 실행하기](#파이썬으로-실행하기)를 참고해 `game.py`를 직접 실행하세요.

## 게임 소개

| 항목 | 내용 |
|---|---|
| 목표 | 발판을 하나씩 밟고 올라가 꼭대기의 초록색 **EXIT** 문에 도착하기 |
| 목숨 | 3개. 화면 아래로 떨어지면 1개를 잃고, 가장 높이 올라갔던 발판에서 부활 |
| 화면 표시 | 왼쪽 위에 현재 층수와 난이도·목표, 오른쪽 위에 남은 목숨(빨간 하트)과 사용한 목숨(회색 하트) |
| 돌발 상황 | 8~10층을 오를 때마다 화면이 번쩍이며 색이 반전됨("모래알이 덮쳐왔다!"). 3층을 더 오르면 원래대로 돌아옴 |

## 게임 제작 과정

### 1단계. 기획

게임을 만들기 전에 네 가지를 먼저 정했습니다.

1. **만들 프로그램을 한 문장으로 쓰기**
   탈출 스토리를 가진 게임 프로그램 제작.
2. **핵심 기능 3개 정하기**
   - 방향키로 주인공 캐릭터를 이동(점프 포함)
   - 점프로 닿을 수 있는 높이에 다양한 모양의 발판이 있고, 발판을 하나씩 올라서 등반. 목숨은 3개이고, 추락하면 가장 높이 있던 층에서 부활
   - 화면 왼쪽 위에 올라온 층수, 오른쪽 위에 남은 목숨 표시
3. **화면 그리기**
   `ex image.png`로 화면 구성을 스케치했습니다(아래 [예시 이미지](#예시-이미지) 참고).
4. **돌발 상황과 해결 방법 정하기**
   일정 층수를 오르면 화면 전체가 번쩍이며 색이 반전되고, 몇 층을 더 오르면 원래대로 돌아오는 것을 반복.

### 2단계. 첫 구현

설치가 필요 없는 파이썬 기본 GUI 라이브러리 **tkinter**로 만들었습니다. 기획에 빠져 있던 부분은 이때 정했습니다.

- 탈출 게임이므로 **도착점**(꼭대기의 EXIT 문)을 둠
- 목숨을 다 쓰면 **게임 오버**, Enter로 재시작
- **추락**은 "화면 아래로 떨어지는 것"으로 정의
- 빠른 깜빡임은 광과민성 발작을 일으킬 수 있으므로 번쩍임 횟수를 제한

### 3단계. 기능 확장

첫 버전을 바탕으로 기능을 추가했습니다.

- **난이도 시스템**: 이지·노말·하드(도착점 30·50·100층)와 끝이 없는 무한 모드
- **색 반전 규칙 변경**: 3~5층마다 → 8~10층마다 무작위로
- **바닷속 배경**: 스케치의 파란 낙서는 바닷속을 표현한 것이었기 때문에, 파란 물결선과 떠오르는 물방울로 배경을 만듦
- **특수 발판**: 무너지는 발판 대신 미끄러운 발판과 느려지는 발판을 추가

### 4단계. 테스트 플레이 후 수정

직접 플레이해 보고 불편한 점을 고쳤습니다.

| 문제 | 수정 |
|---|---|
| 화면 번쩍임이 너무 잦음 | 반전될 때 한 번만 번쩍이도록 변경 |
| 발판 옆 층 번호가 거슬림 | 층 번호 삭제 |
| 왼쪽 위 난이도·목표 글자가 흐림 | 진한 검은색 굵은 글씨로 변경 |
| 난이도가 너무 쉬움 | 발판이 매번 최소 거리 이상 떨어지도록 배치 방식을 바꾸고 최대 간격도 늘림 |
| 하드 100층이 너무 김 | 하드 도착점을 70층으로 낮춤 |
| 반전 안내 문구 | 바닷속 분위기에 맞게 "모래알이 덮쳐왔다!"로 변경 |

간격을 늘릴 때는 **모든 발판이 점프로 닿는지** 시뮬레이션으로 검증했습니다. 가장 먼 간격과 가장 높은 단차가 동시에 나오는 최악의 경우에도, 발판 끝에서 달려 점프하면 모든 난이도에서 다음 발판에 닿습니다.

| 난이도 | 점프로 갈 수 있는 가로 거리 | 최대 간격 | 여유 |
|---|---|---|---|
| 이지 | 165px | 110px | 54px |
| 노말 | 160px | 135px | 24px |
| 하드 | 155px | 145px | 9px |

### 5단계. 웹 배포

tkinter 게임은 브라우저에서 실행되지 않기 때문에, `game.py`의 규칙과 수치를 그대로 JavaScript로 옮긴 웹 버전(`web/index.html`)을 만들어 배포했습니다.

## game.py 설명

게임의 원본이 되는 파이썬 파일입니다. 웹 버전도 이 파일의 규칙과 수치를 그대로 따릅니다.

### 전체 구조

| 부분 | 내용 |
|---|---|
| 설정값 (파일 맨 위) | 화면 크기, 중력, 점프 힘, 이동 속도, 목숨 수, 반전 규칙 등. 숫자만 바꾸면 게임 느낌이 바뀜 |
| `RULES` | 난이도별 발판 규칙(발판 폭, 위아래·가로 간격, 움직이는/특수 발판이 나오는 층과 확률) |
| `MODES` | 모드 이름, 사용할 규칙, 도착 층 |
| `COLORS` / `invert()` | 기본 색상표와, 각 색을 반전한 색상표(색 반전 돌발 상황에 사용) |
| `Platform` 클래스 | 발판 하나. 위치, 폭, 종류(보통·움직임·미끄러움·느려짐·출구)를 가지고, 움직이는 발판은 좌우로 왕복 |
| `Player` 클래스 | 주인공. 위치, 속도, 밟고 있는 발판, 바라보는 방향 |
| `Game` 클래스 | 입력 처리, 게임 진행, 그리기를 모두 담당 |

### 게임이 돌아가는 방식

`Game.loop()`가 약 16ms마다(초당 약 60번) 반복 실행됩니다. 한 번 실행될 때마다 다음을 합니다.

1. `update()`: 키 입력에 따라 주인공을 움직이고, 중력·착지·추락을 계산
2. `update_bubbles()`: 배경 물방울을 위로 이동
3. `draw()`: 화면을 전부 지우고 새로 그림

화면은 `title`(난이도 선택) → `play`(게임 중) → `over`(실패) 또는 `clear`(성공) 상태로 바뀌며, 상태에 따라 입력과 그리기가 달라집니다.

### 주요 메서드

**`update()`: 이동과 물리**

- 좌우 키로 원하는 속도(`target`)를 정합니다. 밟고 있는 발판이 느려지는 발판이면 속도를 40%로 줄입니다.
- 미끄러운 발판에서는 속도를 바로 바꾸지 않고 매 프레임 5%씩만 가까워지게 해서 미끄러지는 느낌을 냅니다.
  ```python
  if surface == "ice":
      p.vx += (target - p.vx) * ICE_GRIP   # 천천히 빨라지고 천천히 멈춘다
  else:
      p.vx = target
  ```
- 매 프레임 중력(`GRAVITY`)을 세로 속도에 더해서 떨어지게 합니다. 점프는 세로 속도를 위쪽(`-JUMP_POWER`)으로 바꾸는 것입니다.
- **착지 판정**: 내려오는 중에 발 위치가 발판 윗면을 지나쳤으면 발판 위에 세웁니다. 올라갈 때는 판정하지 않으므로 아래에서 점프해 발판을 뚫고 올라탈 수 있습니다.
- **카메라**: 주인공이 화면 위쪽 35% 선을 넘으면 화면이 따라 올라갑니다. 내려가지는 않으므로 화면 아래로 떨어지면 추락입니다.

**`add_platform()`: 발판 만들기**

맨 위 발판보다 한 층 위에 새 발판을 놓습니다.

- 위아래 간격은 난이도의 `gap_y` 범위에서 무작위로 정합니다(최대 점프 높이 약 134px보다 작게).
- 가로로는 이전 발판의 왼쪽이나 오른쪽으로 `gap_x` 범위만큼 떨어뜨리고, 벽에 막히면 반대쪽에 놓습니다.
- 무작위로 움직이는 발판, 미끄러운 발판, 느려지는 발판을 섞습니다. 도착 층에는 출구 발판을 놓습니다.

`ensure_platforms()`가 현재 층보다 15층 위까지 미리 발판을 만들어 두기 때문에, 무한 모드에서는 올라가는 만큼 발판이 계속 생깁니다.

**`on_land()` / `check_invert()`: 새 층 도착과 돌발 상황**

새로운 층에 처음 올라서면 최고 층수와 부활 위치를 갱신하고, 도착점이면 게임을 클리어합니다. 그다음 `check_invert()`가 반전 조건을 확인합니다.

- 반전 상태가 아니고 정해 둔 층(`next_invert`)에 도달하면 → 반전 시작, 번쩍임, "3층 뒤 복구" 예약
- 반전 상태이고 복구 층(`revert_at`)에 도달하면 → 원래대로, 다음 반전 층을 8~10층 뒤로 무작위 지정

**`lose_life()`: 추락과 부활**

목숨을 하나 줄이고, 남은 목숨이 없으면 게임 오버입니다. 목숨이 남아 있으면 가장 높이 올라갔던 발판(`best_platform`) 위에서 부활하고, 1초 동안 깜빡입니다.

**`draw()`와 `color()`: 그리기와 색 반전**

모든 그리기 메서드는 색을 직접 쓰지 않고 `self.color("이름")`으로 가져옵니다. 반전 상태면 `INVERTED_COLORS`를, 아니면 `COLORS`를 돌려주므로, 그리기 코드를 고치지 않고도 화면 전체 색을 한 번에 뒤집을 수 있습니다.

```python
def invert(hex_color):
    value = int(hex_color[1:], 16)       # "#eaf7fc" → 16진수 정수
    return f"#{0xFFFFFF - value:06x}"    # 흰색(0xFFFFFF)에서 빼면 반대 색
```

배경의 물결선은 카메라보다 절반 속도로 움직여서(`cam_y * 0.5`) 깊이감을 줍니다.

### 숫자 바꿔 보기

파일 맨 위의 설정값만 바꿔도 게임이 달라집니다.

| 바꿀 값 | 효과 |
|---|---|
| `JUMP_POWER` | 점프 높이 |
| `MAX_LIVES` | 목숨 수 |
| `INVERT_GAP`, `REVERT_AFTER` | 색 반전이 일어나는 간격과 지속 층수 |
| `RULES`의 `gap_x` | 발판 사이 가로 간격 (최대값은 이지 165, 노말 160, 하드 155보다 작게 둬야 점프로 닿음) |
| `MODES`의 숫자 | 난이도별 도착 층 |
